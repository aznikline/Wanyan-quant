# Rock Quant 2.0 - 顽岩量价模型

面向个人量化交易者的轻量级量价策略验证平台

## ✨ 核心特性

- **10+经典量价策略预设**：双均线、MACD、RSI、布林带、OBV能量潮、动量策略等
- **全向量化回测引擎**：移除所有Python循环，速度提升5-10倍
- **20+专业绩效指标**：夏普、卡玛、索提诺、最大回撤、胜率、盈亏比、VAR/CVAR完整计算
- **可视化参数敏感性分析**：双参数热力图，自动标注最优参数区间
- **多维度交易归因分析**：盈亏分布、持仓时长分析、最大盈利/亏损交易分析
- **4种仓位管理模式**：固定仓位、凯利公式、鞅策略、波动率动态调整
- **5种止损止盈模式组合**：固定百分比、移动跟踪止损、波动率自适应止损等
- **一键导出完整回测报告**：支持PDF、CSV、YAML配置文件导出
- **新手引导系统**：三步上手，内置最佳实践案例
- **Streamlit现代化界面**：响应式设计，交互流畅

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install pandas numpy streamlit plotly pyyaml pydantic scipy
```

### 2. 启动应用

```bash
cd RockQuant
streamlit run app.py
```

### 3. 三步完成回测

1. **选择策略**：从左侧边栏选择预设策略
2. **配置参数**：选择标的，调整策略参数和风控规则
3. **查看结果**：点击运行回测，查看完整绩效分析

## 📊 预设策略库

| 策略名称 | 策略描述 | 核心参数 |
|---------|---------|---------|
| 双均线策略 | 短期均线上穿长期均线买入，下穿卖出 | 短期周期、长期周期 |
| MACD策略 | MACD金叉买入，死叉卖出 | 快线、慢线、信号线周期 |
| RSI超买超卖策略 | RSI进入超卖区间买入，超买区间卖出 | RSI周期、超买阈值、超卖阈值 |
| 布林带突破策略 | 价格突破上轨买入，跌破下轨卖出 | 布林带周期、标准差倍数 |

## 🎯 风控与仓位管理

### 仓位管理模式
- **固定仓位**：每次开仓使用固定比例仓位
- **凯利公式**：根据历史胜率盈亏比动态计算最优仓位
- **鞅策略/反鞅策略**：亏损后加倍/减半仓位
- **波动率动态调整**：波动率越高，仓位越低

### 止损止盈模式
- 固定百分比止损/止盈
- 移动跟踪止损
- 波动率自适应止损
- 时间止损
- 技术指标止损

## 📈 绩效指标说明

### 收益类指标
- 总收益率、年化收益率(CAGR)、累计净值
- 月度、年度收益统计

### 风险类指标
- 最大回撤、最大回撤持续天数
- 年化波动率、下行波动率
- 夏普比率、卡玛比率、索提诺比率
- VaR(95%)、CVaR(95%)

### 交易类指标
- 总交易次数、胜率、盈亏比、盈利因子
- 平均单笔收益、平均盈利/亏损交易收益
- 单笔最大盈利/亏损
- 最大连续盈利/亏损天数
- 交易频率

## 🔧 架构设计

### 分层架构
```
┌─────────────────────────────────┐
│   前端交互层 (Streamlit)        │
│   页面路由 | 组件库 | 引导      │
├─────────────────────────────────┤
│   应用服务层                     │
│   策略编排 | 参数校验 | 结果聚合 │
├─────────────────────────────────┤
│   回测引擎层                     │
│   撮合引擎 | 风控模块 | 绩效计算 │
├─────────────────────────────────┤
│   数据层                         │
│   行情源 | 数据清洗 | 因子计算   │
└─────────────────────────────────┘
```

### 核心设计原则
- **所见即所得**：所有参数调整即时生效
- **分层设计**：策略、回测、展示完全解耦，可独立扩展
- **渐进式复杂度**：新手模式只有核心参数，专家模式开放全部配置
- **可复现性**：所有回测结果可以通过唯一配置ID完全复现
