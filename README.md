# Rock Quant 2.2.0 - 顽岩量价模型

面向个人量化交易者的轻量级量价策略验证平台

## ✨ 核心特性

- **20个主流量价策略预设**：双均线、MACD、RSI、布林带、OBV能量潮、KDJ、CCI、WR、ROC、BIAS、DMA、TRIX、均线多头发散、肯特纳通道、成交量突破、VR、DMI、动量策略等
- **全向量化回测引擎**：移除所有Python循环，速度提升5-10倍
- **20+专业绩效指标**：夏普、卡玛、索提诺、最大回撤、胜率、盈亏比完整计算
- **月度收益率热力图**：直观查看不同月份策略表现
- **交易盈亏分布分析**：单笔交易盈亏统计、连续盈亏分析
- **参数敏感性扫描**：支持单参数扫描分析，自动推荐最优参数
- **多策略横向对比**：同一标的多策略对比，雷达图多维度分析
- **多标的批量回测**：同一策略多标的同时回测，综合排名
- **马科维茨组合优化**：自动计算最优权重、相关性矩阵分析
- **策略深度百科知识库**：每个策略7维度详解（发明者、原理、公式、适用场景、A股实盘经验、常见陷阱、改进方向）
- **策略选型矩阵指南**：6种市场状态下的策略适配指南
- **Streamlit现代化界面**：响应式设计，交互流畅
- **专业PDF报告导出**：一键生成完整回测报告，包含绩效指标、净值曲线、月度热力图、风险分析等6大模块

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install pandas numpy streamlit plotly pydantic scipy reportlab matplotlib
```

> PDF报告导出功能需要额外安装 `reportlab` 和 `matplotlib`

### 2. 启动应用

```bash
cd RockQuant
streamlit run Home.py
```

> 注意：主入口文件是 **Home.py**（标准命名），不是 app.py

### 3. 三步完成回测

1. **快速开始**：首页选择4个常用预设，一键进入
2. **配置参数**：左侧边栏选择策略、标的，调整参数
3. **查看结果**：点击「开始回测」，查看完整绩效分析

| 类别 | 策略数量 | 策略名称 |
|-----|---------|---------|
| 趋势跟踪类 | 6个 | 双均线、MACD、DMA、TRIX、均线多头发散、唐奇安通道突破 |
| 震荡反转类 | 7个 | RSI、KDJ、CCI、WR、MOM动量、ROC变动率、BIAS乖离率 |
| 通道突破类 | 2个 | 布林带突破、肯特纳通道突破 |

| 趋势强弱类 | 1个 | DMI趋向指标 |

## 💡 策略选型参考矩阵

| 市场状态 | 首选策略 | 禁用策略 | 核心逻辑 |
|---------|---------|---------|---------|
| 明确单边上涨 | 唐奇安通道、双均线、DMI | RSI、KDJ、WR、BIAS | 趋势策略让利润奔跑，震荡策略会反复卖飞 |
| 明确单边下跌 | 空仓或唐奇安做空 | 所有抄底类震荡策略 | 下跌趋势中任何反弹都是逃命机会，不要抄底 |
| 区间震荡行情 | RSI、KDJ、WR、BIAS、布林带 | 所有趋势突破类策略 | 震荡市高抛低吸，突破策略来回打脸 |
| 横盘末期突破 | 布林带突破、肯特纳通道、成交量突破 | 不要提前赌方向 | 布林带收窄是突破的最强信号之一 |
| V型反转极端行情 | BIAS、ROC、OBV背离 | 所有滞后的趋势类策略 | 极端乖离率是唯一靠谱的反转信号 |
| 不知道什么行情 | 先看ADX值，ADX>25用趋势，ADX<20用震荡 | 不要上来就随便用一个策略 | 先判断有没有趋势，再选策略，这是专业和散户的区别 |

## 🔧 技术栈

- **后端核心**：纯 Python + Pandas (Numpy 向量化计算)
- **数据存储**：Parquet 格式本地缓存
- **可视化引擎**：Plotly (交互式图表)
- **Web框架**：Streamlit 1.57+
- **优化算法**：Scipy (马科维茨优化)
- **参数校验**：Pydantic

## 📊 性能指标

- **单策略回测**：10年数据 < 0.5秒
- **20个策略批量回测**：< 8秒
- **内存占用**：< 500MB
- **并行支持**：单线程（向量化计算已足够快）
